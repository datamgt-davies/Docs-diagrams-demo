# Docs-diagrams-demo
Ability to demonstrate AI compatible documentation

## Initial Instructions

```bash
uv init
uv add --dev zensical
uv run zensical
```
Then activate the virtual environment

```bash
source .venv/bin/activate
```

To bootstrap the site run

```bash
zensical new .
```
